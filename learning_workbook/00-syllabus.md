# Syllabus: Agentic AI for Test Automation
### A Practical Workbook: Local LLMs → Python Agents → MCP

## How This Workbook Works

Every module follows the same pattern: a short explanation of the concept, minimal working code, an exercise that extends it on your own project, and self-check questions before you move on. There's no filler theory: if a section doesn't change what you build or how you defend it in an interview, it isn't here.

Everything builds on **one running project** (your local AI test-automation agent) rather than disconnected toy examples. By the end of Round 1 that project is interview-ready. By the end of Round 2 it's production-grade.

**A note on staleness:** specific model names, version numbers, and tool releases in this space shift within months. The concepts, architecture, and code patterns in each module are written to last; anything version-specific links out to the official source instead of being frozen on the page.
